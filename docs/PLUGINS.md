# Плагины IPTV

Плагин — это один файл `.js`, который меняет список каналов или адрес потока перед включением канала. Один и тот же плагин работает во всех версиях приложения: на Android, на компьютерах, на Samsung и на LG.

## Как подключить плагин

1. Откройте список каналов и перейдите в меню: на пульте — кнопка ◀, на телефоне — кнопка «Меню».
2. Выберите **Плагины**.
3. Вставьте ссылку на файл плагина и подтвердите.

Подойдёт обычная ссылка на файл в GitHub, например
`https://github.com/volnalabs/IPTV/blob/main/plugins/sort-by-name.js` — приложение само превратит её в прямую ссылку на содержимое файла.

| Действие | Пульт, клавиатура | Мышь, сенсорный экран |
|---|---|---|
| Включить или выключить | ОК | Нажатие |
| Удалить | Удерживать ОК (на компьютере ещё Delete) | Долгое нажатие, на компьютере — правая кнопка |

На Android изменения применяются сразу. На компьютерах, Samsung и LG приложение перезапускается само, когда вы выходите с экрана плагинов.

На телевизоре с Android длинную ссылку удобнее прислать с телефона: **Настройки → «С телефона»**, в открывшейся форме есть поле «Плагин».

> [!WARNING]
> Ставьте только те плагины, авторам которых доверяете. Плагин видит весь список каналов и ссылки из вашего плейлиста (в них часто зашит личный ключ провайдера) и может отправить их куда угодно.

Приложение хранит копию плагина на устройстве, поэтому он работает и без интернета. При каждом запуске приложение проверяет, не изменился ли файл по ссылке; новая версия начинает работать со следующего запуска.

## Первый плагин за пять минут

Создайте файл `my-plugin.js`:

```js
IPTV.plugin({
  id: 'my-plugin',              // обязательное поле, латиницей, без пробелов
  name: 'Мой плагин',
  version: '1.0',
  description: 'Ставит новостные каналы в начало списка',
  author: 'ваше имя',

  playlist: function (channels, api) {
    var news = channels.filter(function (c) { return c.group === 'Новости'; });
    var rest = channels.filter(function (c) { return c.group !== 'Новости'; });
    return news.concat(rest);
  }
});
```

Выложите файл на GitHub ([как это сделать](#как-выложить-плагин-на-github)) и подключите его по ссылке. Всё.

## Справочник

### `IPTV.plugin(описание)`

Регистрирует плагин. В одном файле — один вызов.

| Поле | Обязательное | Что это |
|---|---|---|
| `id` | да | Короткое имя латиницей. По нему приложение отличает плагины друг от друга |
| `name` | нет | Название на экране «Плагины» |
| `version` | нет | Версия, показывается рядом с названием |
| `description` | нет | Одна строка о том, что делает плагин |
| `author` | нет | Автор |
| `start(api)` | нет | Вызывается один раз при запуске приложения |
| `playlist(channels, api)` | нет | Вызывается после загрузки плейлиста. Верните новый список каналов |
| `stream(channel, api)` | нет | Вызывается перед включением канала. Верните адрес потока |

`IPTV.apiVersion` — номер версии интерфейса плагинов, сейчас `1`.

### Канал

Объект канала в `playlist` и `stream`:

| Поле | Тип | Что это |
|---|---|---|
| `name` | строка | Название |
| `url` | строка | Адрес потока |
| `group` | строка | Группа |
| `logo` | строка | Ссылка на логотип, может быть пустой |
| `number` | число | Номер в списке. После плагинов приложение нумерует каналы заново |
| `tvgId`, `tvgName` | строка | По ним канал связывается с телепрограммой |
| `catchup` | строка | Тип записи передач (`shift`, `append`, `default`, `flussonic`) или пусто |
| `catchupDays` | число | На сколько дней назад есть записи |
| `catchupSource` | строка | Шаблон адреса записи из плейлиста |
| `archive` | да/нет | Только в `stream`: `true`, если включается запись, а не прямой эфир |

### `playlist(channels, api)`

Получает массив каналов и возвращает массив каналов. Каналы можно убирать, переставлять, переименовывать, переносить в другие группы и добавлять новые — у нового канала должны быть хотя бы `name` и `url`. Записи без названия или адреса приложение отбросит.

Если функция ничего не вернула или упала с ошибкой, список остаётся прежним.

### `stream(channel, api)`

Получает канал, который сейчас включится. В `channel.url` уже лежит готовый адрес — для записи это адрес записи. Верните строку с новым адресом. Если вернуть что-то другое, адрес не изменится.

### `api`

| Что | Описание |
|---|---|
| `api.apiVersion` | Версия интерфейса плагинов (`1`) |
| `api.version` | Версия приложения, например `1.0.5` |
| `api.platform` | `android`, `desktop`, `samsung` или `lg` |
| `api.toast(текст)` | Короткое сообщение на экране |
| `api.log(текст)` | Запись в журнал — см. [отладку](#отладка) |
| `api.storage.get(ключ, поУмолчанию)` | Прочитать сохранённое значение |
| `api.storage.set(ключ, значение)` | Сохранить значение на устройстве. Годится всё, что превращается в JSON |

Хранилище общее для всех плагинов, поэтому начинайте ключи с имени своего плагина: `my-plugin.quality`.

## Правила и ограничения

- **Пишите на ES5.** Телевизоры Samsung и LG 2016–2018 годов не понимают `let`, `const`, стрелочные функции, `async`, шаблонные строки и `class`. Используйте `var` и `function`.
- **Функции должны отвечать сразу.** `playlist` и `stream` — обычные функции: то, что вернётся из `Promise` или придёт из сети позже, приложение не увидит. Если нужны данные из сети, загрузите их в `start`, сохраните через `api.storage` и используйте при следующем вызове.
- **Не затягивайте.** На Android приложение ждёт ответа `playlist` 8 секунд, `stream` — 1,5 секунды, после чего включает канал с исходным адресом.
- **Запросы в сеть.** На компьютере доступны любые адреса. На Android, Samsung и LG действуют правила браузера: сервер должен разрешать запросы с других сайтов (заголовки CORS).
- **Экрана у плагина нет.** Плагин не может добавить свои кнопки или пункты меню — только менять каналы и адреса.
- **Ошибка в плагине не ломает приложение:** она попадает в журнал, а приложение работает дальше так, будто плагина нет.
- Плагины выполняются по очереди, в том порядке, в каком добавлены: следующий получает список после предыдущего.

## Как выложить плагин на GitHub

1. Создайте публичный репозиторий (или возьмите существующий).
2. Нажмите **Add file → Create new file**, назовите файл, например `my-plugin.js`, вставьте код и нажмите **Commit changes**.
3. Откройте файл и скопируйте ссылку из адресной строки — её и вставляйте в приложение.

Чтобы выпустить новую версию, просто отредактируйте файл и поменяйте `version`. У пользователей плагин обновится сам при следующем запуске приложения.

Подойдёт и любой другой хостинг, который отдаёт файл по прямой ссылке.

## Отладка

Проще всего проверять плагин в версии для компьютера: она ведёт себя так же, как версии для телевизоров.

- **Компьютер.** Запустите приложение из терминала с ключом `--enable-logging` — строки `api.log` и ошибки плагинов появятся в терминале с пометкой `[plugin]`.
- **Android.** `adb logcat -s IptvPlugins`
- **Проверка без приложения.** Плагин — обычный JavaScript, его легко прогнать в Node.js вместе со средой выполнения из этого репозитория:

```js
// node check.js
var fs = require('fs'), vm = require('vm');
var box = { localStorage: { getItem: function () { return null; }, setItem: function () {} } };
box.window = box;
vm.createContext(box);
vm.runInContext(fs.readFileSync('shared/plugin-runtime.js', 'utf8'), box);
box.__iptvPlugins.setHost({ version: '1.0.0', platform: 'desktop', log: console.log, toast: console.log });
vm.runInContext(fs.readFileSync('my-plugin.js', 'utf8'), box);
box.__iptvPlugins.start();
console.log(box.__iptvPlugins.playlist([
  { name: 'Первый', url: 'http://example.com/1.m3u8', group: 'Новости' }
]));
```
