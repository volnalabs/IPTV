# Отступления от спецификации

Формат: что → где → почему. Источник истины — `docs/design/handoff/SPEC.md`.

## Правки после приёмки на телевизоре (12.11.2026)

По просьбе владельца после проверки на настоящем Android TV. Касаются ТВ-вида web (Samsung, LG, полный экран компьютера) и Android TV одинаково.

| Что | Где | Почему |
| --- | --- | --- |
| Номер канала без ведущих нулей: «1», а не «0001» | `numText()` (web, Android) | SPEC 3.1/4.1 ставят номер с нулями до 3–4 знаков; на телевизоре «0001» не помещался в колонку номера и залезал под плитку. В плитках гида номер из 4 знаков — 40 px, из 5 — 32 px |
| В эфире нет панели кнопок (SPEC 4.2): OK открывает гид целиком | `playOk()`, `ctlButtons()` | Владелец попросил убрать ряд кнопок внизу. Панель осталась только у записи (перемотка, пауза, «Вернуться в эфир», «О передаче», «Телепрограмма»). Что было на панели эфира, доступно иначе: каналы — OK и ◀, ▲▼ — пульт, «Предыдущий» — LAST/Backspace, «О передаче» — INFO, сетка — удержание OK → «Найти в сетке телепрограммы», записи — ▶, громкость и «Без звука» — кнопки пульта, избранное — зелёная и удержание OK, «Ещё» → настройки и плагины — синяя и «Настройки» в гиде, «Убирать чёрные полосы» — «Настройки → Воспроизведение» |
| Мини-гида (SPEC 3.3) нет: ◀ в эфире открывает гид с разделами, каналами и программой | `openGuide()` | Владелец попросил сразу открывать полный гид вместо отдельного списка каналов |
| В OSD стрелки: ◀ у логотипа (список каналов), ▶ справа (программа канала), обе по центру высоты логотипа; номер канала по центру между ▲ и ▼ | `renderOsd()` | Подсказка, что ◀ и ▶ работают. В записи стрелок нет — там ◀▶ перематывают. Стрелки кликабельны (мышь, указка LG) |
| Поиск на Android TV — своя экранная клавиатура, как в web и макете TV-Search, без системной | `TvLayers.buildSearch()`, `keySearch()` | Раньше на Android было поле с системной клавиатурой. Буквы с настоящей клавиатуры и цифры пульта по-прежнему попадают в строку |
| В OSD нет следующей передачи (время и название после разделителя) | `renderOsd()` | SPEC 4.1 показывает «дальше: время · название»; владелец попросил убрать — строка обрезалась и выглядела неаккуратно. Следующие передачи видны по ▶ в программе канала |
| Во время просмотра заставка телевизора не включается: Android — `FLAG_KEEP_SCREEN_ON`, пока поток идёт или подгружается; Samsung — `webapis.appcommon.setScreenSaver(OFF)`; на паузе записи, при ошибке и в фоне — снова как решит система | `MainActivity.keepScreenOn()`, `screenSaver()` | Телевизор уходил в заставку посреди эфира: в эфире нет нажатий, а приложение не сообщало системе, что идёт видео. LG сам не включает заставку при воспроизведении `<video>` |
| «Настройки» на ТВ — круглая кнопка с шестерёнкой справа от часов в шапке гида, а не последний пункт меню | `renderHead()`, `keyGroups()`, `#gset` / `TvLayers.gSet` | Владелец попросил: до «Настроек» приходилось листать меню до конца. ▲ с «Поиска» — в шапку (при нескольких плейлистах сначала на плейлист, ▶ — на шестерёнку). Освободившееся место отдано шестой строке групп. Значка-шестерёнки в наборе SPEC нет — нарисован в том же стиле (24×24, линия 1,8): `ICON.gear`, `ic_gear.xml`. На компьютере «Настройки» остались в меню |
| Рамки фокуса и «играет» у плиток гида на Android больше не срезаются справа | `TvLayers.renderTiles()` | Строка плитки была 476 px холста, а рамка заканчивается на 490 |
| Сетка, открытая из гида, прячет гид под собой | `openGrid()`, `closeGrid()` | Полупрозрачный фон сетки показывал гид насквозь; «Назад» возвращает гид |

## Процесс

| Что | Где | Почему |
| --- | --- | --- |
| Этапы 2–6 для web сделаны одним коммитом, а не пятью | `web/app.js`, `web/style.css`, `web/index.html` | Гид, плеер, поиск и настройки делят одни зоны `S.zone` и общий рендер; промежуточные состояния не собирались бы. Android идёт отдельными коммитами |

## Web (Samsung, LG, Desktop)

| Что | Где | Почему |
| --- | --- | --- |
| Экранная клавиатура — 32 буквы, без «Ё» | `kbRows()` | В макете TV-Search ряд из 8 клавиш × 4 = 32; поиск считает «ё» = «е», поэтому буква не нужна. SPEC говорит «33 буквы» |
| Клавиша переключения раскладки в латинице подписана «РУ» | `kbRows()` | В SPEC есть только «EN»; обратного названия нет, а без него из латиницы не вернуться |
| В сетке ▲ с первой строки ведёт в шапку (вкладки дней и выбор группы), ▼ — обратно | `keyGrid()` | В таблице 8.2 для сетки переходов в шапку нет, но вкладки и группа нарисованы в макете; без этого перехода с пульта до них не добраться |
| Недоступные кнопки панели («Предыдущий канал», «Телепрограмма», «−30 с», «+30 с») пропускаются фокусом; «Записи» без архива фокус получает и даёт тост | `keyCtl()`, `ctlPress()` | SPEC описывает поведение фокуса только для «Записей» |
| «M — без звука» срабатывает только на латинской «M»; кириллическая «ь» на той же клавише открывает поиск | `handleKey()` | SPEC одновременно требует «буквы открывают поиск» и «M — без звука» |
| Samsung: кнопки VOL±/MUTE не регистрируются, шкалу громкости показывает телевизор; своё «Без звука» работает, только если доступен `tizen.tvaudiocontrol` (добавлена привилегия `tv.audio`) | `VOL`, `samsung/config.xml` | SPEC 7.4, 10.3 п. 3: доступ не подтверждён без устройства; выбрано поведение по умолчанию |
| LG: шкала громкости не показывается, «Без звука» — `video.muted` + значок | `VOL`, `showVol()` | SPEC 7.5 |
| Состояние «Есть звук, нет изображения» работает только с `<video>` (LG, Desktop) | `playing()` | У AVPlay нет `videoWidth`; SPEC 4.4 это допускает |
| Код 403/404 потока определяется только через hls.js | `start()`, `playFailed()` | SPEC 10.3 п. 9: AVPlay и прямой `<video src>` кода не отдают — там «Канал не включился» с повторами |
| Убывающая полоска таймера ввода номера идёт 1–3 с (дольше 240 мс) | `numArm()` | Это индикатор таймера из SPEC 3.6 («убывает линейно»), а не декоративная анимация; анимируется `transform`, на `body.lite` отключена |
| Колесо указки над плитками каналов двигает выбор, а не прокручивает список | обработчик `wheel` | В режиме плиток «прокрутки без фокуса» нет: фокус всегда на второй позиции |
| Если при запуске список не загрузился и сохранённого нет, открывается гид с состоянием «В плейлисте нет каналов» и тостом причины | `loadFailed()` | В SPEC нет экрана для «плейлист задан, но каналов нет вообще»; первый запуск (O1) показывается только без плейлиста |
| В меню удержания OK на плейлисте есть пункт «Изменить», а «Обновить» у неактивного плейлиста перепроверяет ссылку и число каналов | `playlistMenu()`, `recheckPlaylist()` | «Изменить» есть в Desktop-варианте SPEC 5.2; для неактивного плейлиста обновлять нечего, кроме проверки ссылки |
| Тексты, которых нет в SPEC дословно: пояснения первого запуска («Нажмите OK на поле — откроется клавиатура телевизора.», «Ссылку можно вставить из буфера обмена: Ctrl+V.», «Вставьте ссылку на плейлист от вашего провайдера — и можно смотреть.» — из прежней версии), подсказка поля названия «Пусто — имя сервера из ссылки», статусы строки фокуса сетки («идёт сейчас, до …», «запись есть» — взяты из результатов поиска), тосты «Загружаем «…»…», «Телепрограмма не загружена», «Не удалось обновить список: …» | `renderOnb()`, `paneItems()`, `gridStatus()`, `activatePlaylist()` | SPEC называет эти элементы («пояснение про клавиатуру», «тост-предупреждение с причиной»), но не даёт формулировок; взяты ближайшие из SPEC и прежнего интерфейса |

## Android

| Что | Где | Почему |
| --- | --- | --- |
| На Android 5–7 (API 21–25) шрифт Onest не применяется, остаётся системный | `res/font/onest.xml`, `styles.xml` | `android:fontFamily="@font/…"` в теме работает с API 26; подключать AppCompat ради шрифта — смена архитектуры |
| Onest TTF — статические начертания, собранные из вариативного файла Google Fonts, с набором кириллица + латиница | `res/font/onest_*.ttf` | В `@fontsource/onest` только WOFF/WOFF2; Android нужен TTF |
| Фокус в Android ведёт сам экран (зоны, как в web), а не системный фокус View | `BaseActivity`, `TvLayers`, `SettingsActivity` | Переходы должны точно совпадать с таблицей SPEC 8.1 («Назад» снимает один слой, ▲ с «Поиска» — в заголовок и т. д.); системный поиск фокуса между колонками этого не гарантирует. Строки и плитки по-прежнему доступны для касаний и TalkBack через `contentDescription` |
| Гид, плеер и настройки Android собраны из View в коде, без layout-XML; плитки гида — не `RecyclerView`, а 4–5 перерисовываемых View | `TvLayers.kt`, `TouchUi.kt`, `Ui.kt` | Так плитки стоят «фокус на второй позиции» без докрутки и без пропуска кадров при удержании ▼ (SPEC 10.3 п. 6); в разметке одновременно не больше 5 плиток. Списки на телефоне — `RecyclerView` |
| Плагины на Android — раздел `SettingsActivity`; `PluginsActivity` оставлен как переход в этот раздел | `PluginsActivity.kt` | SPEC 5.1: «Плагины» — раздел настроек; отдельное Activity больше не нужно, но его имя могло сохраниться во внешних ссылках |
| CH LIST на Android TV — кнопка «Содержание» (`KEYCODE_TV_CONTENTS_MENU`); на пультах без неё гид открывается через OK → «Каналы» или ◀ ◀ | `Base.kt` | В Android нет кода кнопки «Список каналов» |
| Удалённый плагин на Android удаляется сразу, «Вернуть» ставит запись обратно на прежнее место | `Plugins.remove/restore` | На Android плагины применяются сразу (SPEC 6.4), поэтому держать запись «в памяти 6 с» не нужно — результат для человека тот же |
| Громкость на Android TV: ▲▼ громкости меняют системный поток музыки и показывают нашу шкалу; если громкость фиксирована (управляет телевизор или ресивер), шкалу показывает система. «Без звука» — громкость плеера | `MainActivity.onVolumeKey` | SPEC 7.1 называет `player.volume`; уровень плеера выше 1 не поднять, поэтому шкала отражает системную громкость, а «Без звука» — плеер |
| Тайм-аут плагина на Android записывается как ошибка первого включённого плагина с этим вызовом | `Plugins.timedOut` | Скрытая страница не сообщает, какой из плагинов не ответил |
| Полоска таймера ввода номера обновляется таймером каждые 50 мс, а не аниматором | `TvLayers.numArm` | Идёт по тем же часам, что и таймер переключения (в тестах Robolectric аниматор проматывал часы) |
| Сетка на планшете — прокручиваемая лента на 12 часов (−1 ч … +11 ч), до 60 каналов группы | `TouchUi.openGrid` | SPEC 3.4: «горизонтальная прокрутка жестом, строка 64 dp»; окно и предел выбраны, чтобы не создавать тысячи ячеек |

## Desktop (Electron)

| Что | Где | Почему |
| --- | --- | --- |
| Сетка, настройки, плагины, первый запуск и диалоги на компьютере — ТВ-холст 1920×1080, уменьшенный под окно, а не отдельная вёрстка в px окна | `deskLayout()` | Режим окна сделан для главного экрана (шапка, разделы, список, плеер, программа, поиск), как требует SPEC 7.6; остальные слои работают той же логикой и мышью, но в масштабе холста. Отдельная вёрстка «форма до 760 px» и сетка «9 строк, окно 3 ч» — следующий шаг |
| Полный экран компьютера — ТВ-вид (OSD со стрелками, гид), а не макет Desk-Player | `onFullChange()`, `fit()` | SPEC 7.6: «текущий ТВ-вид доступен в полноэкранном режиме»; подсказки клавиш справа сверху (Esc, ↑ ↓, Backspace, M) добавлены |
| F11 в Electron включает полный экран страницы (`requestFullscreen`), а не окна | `desktop/main.js` | Тогда интерфейс знает о полном экране и переключает раскладку, а Esc возвращает окно. Старые установки (без новой оболочки) по-прежнему переключают окно, интерфейс при этом остаётся в режиме окна |
| Слои плеера (загрузка, ошибки, ввод номера, громкость) в окне — ТВ-холст, вписанный в прямоугольник плеера | `#stage` | Те же состояния SPEC 4.4 без второй вёрстки |
| Подписи подсказок в полном экране: «Выйти из полного экрана», «Каналы», «Предыдущий», «Без звука» | `fullHints()` | Взяты из макета Desk-Player |
| Класс полосы прогресса «текущей» передачи переименован в `.lv` | `bar()`, `style.css` | Совпадал с меткой «Эфир» (`.live`) и сжимал полосу |
