# IPTV — пакет передачи в разработку

Редизайн «Тихий эфир» для volnalabs/IPTV. Положите папку в репозиторий как `docs/design/handoff/`.

| Что | Где |
| --- | --- |
| Полная спецификация (11 разделов) | `SPEC.md` (+ `screen-map.png`) |
| Промт для Claude Code | `CLAUDE_CODE_PROMPT.md` |
| Токены | `tokens/tokens.json`, `tokens/tokens.extra.json`, `tokens/tokens.css`, `tokens/android/colors.xml`, `tokens/android/dimens.xml` |
| Иконки (48) | `icons/*.svg`, `icons/icons.json` |
| Шрифт Onest (OFL) | `fonts/*.woff2`, `fonts/*.woff`, `fonts/onest.css` |
| Эталонные макеты | `screens/*.jpg` — все экраны ТВ, компьютера, телефона, планшета, спецификации и аудита |
| Сценарии прототипа | `flows/tv-*.jpg`, `flows/desk-*.jpg`, `flows/phone-*.jpg` |
| Правила дизайн-системы | `design-system/*.md` |
| CSS макетов (только справка) | `reference/screens.css`, `reference/ds-components.css` |

Живые версии: спецификация — https://claude.ai/artifact/QKyXtWdjNzxv8US3RdwXjS, макеты и интерактивный прототип — https://claude.ai/artifact/Wvxbggj4a3edB9JAC5j39K.

Каналы, передачи и логотипы на макетах — иллюстрация. Кадры `flows/desk-*` и `flows/phone-*` сняты до последней правки подсказок клавиш; вид подсказок — по `screens/` и SPEC 3.1.
