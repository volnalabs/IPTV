# Сетка, размеры, радиусы

## Единицы

Все токены отступов и размеров записаны в dp (Android) = CSS px (компьютер, телефонный веб). **Холст ТВ** (веб-версия для Samsung и LG рисует экран 1920×1080 и масштабирует его под телевизор) = dp × 2. Поэтому `space-6` (24) на ТВ — это 48 px холста, а `radius-md` (6) — 12. Android TV работает в dp напрямую (экран 960×540 dp), и значения совпадают с холстом, делённым на 2.

## Базовая сетка и отступы

Шаг 4. Используются только ступени `space-1` 4 · `space-2` 8 · `space-3` 12 · `space-4` 16 · `space-5` 20 · `space-6` 24 · `space-8` 32 · `space-10` 40 · `space-12` 48 · `space-16` 64.

| Где | Отступ |
|---|---|
| Иконка ↔ подпись в кнопке, пункте меню | `space-2` |
| Номер ↔ логотип ↔ текст в строке канала | `space-3` (ТВ 24 холста) |
| Поля строки списка по горизонтали | `space-3`–`space-4` |
| Поля панели / диалога | `space-6` компьютер, `space-5` телефон, 48 холста ТВ |
| Между зонами гида | разделитель 1 px, без зазора; на компьютере `space-8` между панелями |
| Между группами настроек | `space-6` + заголовок секции |

## Радиусы и линии

| Токен | Значение | Где |
|---|---|---|
| `radius-none` | 0 | Видео, поверхность гида и панели во всю высоту |
| `radius-xs` | 2 | Шкалы прогресса |
| `radius-sm` | 4 | Метки, клавиши, чекбоксы |
| `radius-md` | 6 | Кнопки, поля, строки, пункты меню, плитка логотипа |
| `radius-lg` | 10 | Меню, тост, диалог, ввод номера, верх нижнего листа |
| `radius-full` | 999 | Только переключатель, ползунок, точка эфира |

Линии: `border-hairline` 1 px (ТВ — 2 px холста) для разделителей `line-subtle` и границ `line-control`; кольцо фокуса `focus-ring-width` 2 px с зазором `focus-ring-offset` 2 px.

## Безопасные зоны ТВ

Ничего значимого ближе `tv-safe-x` = 96 px и `tv-safe-y` = 54 px холста к краю (5 %): часть телевизоров обрезает края. Фон гида и затемнение доходят до края, текст и элементы — нет.

## Ширина контента

- Компьютер: контент настроек и плагинов — до `size-content-max` 1200, колонка форм и текста — до `size-reading-max` 640, диалог — до `size-dialog-max` 480. Боковая навигация — `size-sidebar-desk` 240.
- ТВ: гид занимает всю ширину внутри безопасных полей; диалог — 960 холста.
- Телефон: поля 16 dp, контент на всю ширину.

## Адаптация между разрешениями

| Ширина окна / экрана | Раскладка |
|---|---|
| ТВ 1280×720 … 3840×2160 | Холст 1920×1080 масштабируется целиком; 4K получает тот же холст ×2. Шрифты и линии не уменьшать. |
| Компьютер < 900 px | Одна колонка: видео + выдвижная панель каналов |
| Компьютер 900–1399 px | Видео + панель каналов справа (360); программа — вкладкой в панели |
| Компьютер ≥ 1400 px | Видео + каналы + программа (группы — выпадающим списком над каналами) |
| Телефон, портрет | Видео 16:9 сверху, ниже вкладки «Каналы / Программа» |
| Телефон, альбом | Видео на весь экран, список — выдвижной панелью слева |
| Планшет ≥ 840 dp | Две панели: видео и «сейчас/далее» слева, каналы и программа справа |

На компьютере интерфейс больше не масштабируется целиком: размеры в CSS px, раскладка меняется по ширине окна.
