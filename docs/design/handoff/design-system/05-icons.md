# Иконки

Иконки — собственный набор приложения: 19 перенесены без изменений из `web/app.js` и `res/drawable/ic_*.xml`, 17 дорисованы в том же стиле для плеера и состояний. Файлы — в группе ассетов Icons, для веба те же пути лежат в `window.IPTV.icons` (`components/bundle.js`).

## Построение

- Сетка 24 × 24, рабочее поле 20 × 20 (отступ 2).
- Линия 1.8, концы и соединения скруглённые, без заливки. Исключения: `star-filled`, `play-filled` (заливка — «включено»), `playing` (три столбика толщиной 3.4).
- Простые геометрические формы, без перспективы и мелких деталей: иконка читается в 16 px.
- Новая иконка рисуется по этим правилам и добавляется в обе реализации одновременно.

## Размеры

| Размер | Где |
|---|---|
| 16 | Пункты меню, статусы в строках (компьютер) |
| 20 | Кнопки, строки списков, настройки (компьютер, телефон) |
| 24 | Контролы плеера, пустые состояния |
| 28 | Пустые и ошибочные состояния |
| 40 холста (20 dp) | ТВ: строки, кнопки, навигация |

## Цвет

- По умолчанию — цвет текста родителя: `text-primary` в кнопках и меню, `text-secondary` в строках и статусах, `text-tertiary` в полях и пустых состояниях.
- `accent` — только `playing` («этот канал играет») и `play-filled` у записи, которую смотрят.
- `error`, `warning`, `success` — только `alert`, `warning`, `offline`, `check` в статусах и всегда рядом с текстом.
- На `paper` — `text-inverse-secondary`.

## Значения

| Иконка | Значит | Не использовать для |
|---|---|---|
| `history` | Есть запись передачи | «Недавние» (такой функции нет) |
| `playing` | Канал сейчас играет | Громкость, эквалайзер |
| `star` / `star-filled` | Не в избранном / в избранном | Рейтинг |
| `previous` | Предыдущий канал | «Назад» в навигации (это `back`) |
| `frame` | Формат кадра | Полный экран (это `fullscreen`) |
| `guide` | Телепрограмма | Настройки вида |
| `list` | Список каналов | Меню «ещё» (это `more`) |

## Иконка без подписи

Допустима только в контролах плеера, кнопке «ещё» и кнопке избранного в строке. У неё всегда есть подпись для чтения с экрана и tooltip на компьютере («Предыдущий канал · Backspace»); на ТВ рядом с иконкой в панели плеера пишется подпись, кроме перемотки и паузы.
