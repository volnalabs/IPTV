# Платформы

Общее для всех: токены цвета, шрифт, иконки, тексты, смысл состояний. Разное: размеры, раскладка, способ ввода и то, где живут вторичные действия.

## ТВ — Android TV, Samsung, LG

- **Ввод:** D-pad, OK, Назад, ▲▼ канала, цифры, цветные кнопки (если есть), указка LG — как мышь.
- **Масштаб:** холст 1920×1080 (Android TV — 960×540 dp), безопасные поля 96 / 54.
- **Фокус:** заливка `paper`, без увеличения. Один фокус на экране, память выбора в каждой колонке.
- **Гид:** одна поверхность на `scrim`, три зоны: разделы (сворачиваются до названия группы, когда фокус в каналах), каналы (8 строк по 104), программа. Без программы — две зоны.
- **Вторичные действия:** удержание OK → контекстное меню; OK в плеере → панель управления. Каждое действие с цветной кнопки доступно и через D-pad.
- **Подсказки:** не больше трёх, только скрытые действия; со временем исчезают.
- **Текст:** не меньше `tv-meta` 28 px холста; названия в одну строку.
- **Тени и размытие:** нет.

## Компьютер — Windows, macOS, Linux

- **Ввод:** мышь, колесо, клавиатура (стрелки, Enter, Esc, Backspace, 0–9, буквы — поиск, F11). Правая кнопка и Shift F10 — контекстное меню.
- **Масштаб:** настоящие CSS px, раскладка по ширине окна (< 900 / 900–1399 / ≥ 1400), без масштабирования холста.
- **Фокус:** кольцо только для клавиатуры; наведение — подложка `surface-3`, не путается с фокусом.
- **Плеер:** нижняя полоса контролов появляется при движении мыши; щелчок по видео — показать/скрыть, двойной — полный экран; шкала записи перетаскивается.
- **Подсказки клавиш:** в tooltip у кнопок и в меню, строка подсказок — только при работе с клавиатуры.
- **Тени:** `shadow-popover` у меню, контекстного меню, тоста.
- **Заголовок окна:** «Канал — Передача».

## Телефон — Android

- **Ввод:** касание, долгое нажатие (контекстное меню), свайп вниз (закрыть лист), двойное касание слева/справа по видео (±30 с в записи).
- **Портрет:** видео 16:9 сверху; под ним строка «канал · сейчас · далее», вкладки «Каналы / Программа», кнопка текущей группы (открывает лист групп), поиск и настройки значками.
- **Альбом:** видео на весь экран; касание показывает контролы; список — выдвижной панелью слева.
- **Зоны касания:** 48 dp минимум, звезда избранного — кнопка 48 dp.
- **Диалоги:** кнопки во всю ширину, основная — снизу.
- **Цифр нет:** ввод номера не показывается; номер набирается в поиске.

## Планшет — Android

- **До 840 dp ширины** — как телефон.
- **От 840 dp:** две панели. Слева видео и «сейчас / далее», справа вкладки «Каналы / Программа» или, в альбоме, каналы и программа рядом. Группы — боковой список, как на компьютере.
- Полный экран — кнопкой или поворотом, панели возвращаются касанием.
- Размеры — телефонные (48 dp), шрифт — телефонная шкала.
